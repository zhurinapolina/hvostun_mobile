# Хвостун — передача в разработку (мобильная версия пилота)

Версия от 11 ноября 2026 (первая — 8 ноября). Документ для бэкенда и фронтенда: какие экраны есть, какие данные они показывают и сохраняют, какие правила и ошибки, какие запросы к серверу понадобятся.

**Источники и приоритет.**
1. Макеты новой палитры (`mockups/`) и кликабельный прототип (`prototype/index.html`) — самые свежие решения.
2. «ТЗ на макеты, общая зона и чат, версия 2» от 26.10.2026 — требования к поведению, которые не видны на макетах (сервер, аналитика, лимиты).
3. Где макеты и ТЗ расходятся, действуют макеты; расхождения перечислены в разделе 11.

Пометки: **[Макет]** — нарисовано и согласовано; **[ТЗ]** — из ТЗ, на макетах не видно; **[Предложение]** — моё предложение для разработки, не согласовано; **[Открыто]** — решения нет.

Прототип только изображает сервис: вход пускает с любым логином, данные живут, пока открыта страница, ответы чата заготовлены. Всю серверную часть нужно сделать с нуля.

## 2. Состояние пользователя и доступ к разделам

Всё, что видит пользователь, определяется двумя статусами. Их удобно отдавать с сервера одним запросом (см. раздел 9).

| Статус | Значения | Как меняется |
|---|---|---|
| `profile` | `none` → `partial` → `done` | `partial` — в форме что-то введено и пользователь ушёл «Назад» или в меню; `done` — форма прошла проверку и сохранена |
| `survey` | `none` → `started` → `done` | `started` — нажата «Заполнить анкету» на S5; `done` — нажата «Сформировать профиль» на последней перебивке |

**Главная [Макет]:**

«Следующий шаг» — подсказка без стрелки, сама не нажимается; переход — через карточки главной [Макет].

| Состояние | Условие | «Следующий шаг» | Особенности |
|---|---|---|---|
| A | `profile=none` | «Заполнить профиль» (карточка профиля → S4) | План и чат закрыты: «Откроется после заполнения профиля» |
| A2 | `profile=partial` | «Продолжить заполнение» (карточка профиля → S4 с введёнными данными) | Как A |
| B | `profile=done`, `survey=none` | «Получить план» (карточка плана → S5) | Вместо «Привет!» — кличка собаки |
| C | `survey=started` | «Продолжить анкету» | Карточка плана: «Вопрос N из 42, продолжить» (до вопросов — «Раздел N из 8, продолжить») → то место анкеты, где остановились |
| D | `survey=done` | блок скрыт | |

«Связаться со специалистом» во всех состояниях закрыта: «Консультация специалиста. Сервис в разработке.» [Макет]. Внизу ссылка «Написать команде».

**Нижнее меню (Главная, Профиль, План, Чат) [Макет]:**

| Пункт | Доступен, когда |
|---|---|
| Главная | всегда |
| Профиль | `profile=done` (при заполнении формы он активен как текущий экран) |
| План | `survey` ≠ `none`; при `started` ведёт в анкету на сохранённое место, при `done` — на S9. Начать анкету можно только с главной |
| Чат | `profile=done` |

Недоступный пункт просто серый, без замков и бейджей; что делает нажатие на него — [Открыто].

## 3. Вход (S1, S2)

- Логин и пароль выдаются участникам пилота вручную. Регистрации, смены и восстановления пароля нет; восстановление — через «Написать команде» [ТЗ].
- Поля «Логин» и «Пароль» (кнопка «показать пароль»). Чекбокс «Даю согласие на обработку персональных данных», по умолчанию не отмечен, показывается при **каждом** входе. Слова «согласие на обработку персональных данных» — ссылка на текст в Google Документе, в новой вкладке [Макет, ТЗ].
- «Войти» неактивна, пока чекбокс не отмечен (отдельной ошибки нет) [Макет].
- Во время входа кнопка показывает загрузку, поля блокируются. Успех → главная [Макет].
- Ошибка E2: плашка «Логин или пароль не подошли» над полями [Макет].
- Из ТЗ, на макетах новой палитры не нарисованы: E3 «Слишком много попыток. Попробуйте через N минут» (число попыток и время — [Открыто]), E5 «Сессия закончилась. Войдите снова» (время жизни сессии — [Открыто]).
- При каждом входе сохранять факт согласия и **версию текста согласия** [ТЗ].
- «Выйти» — на вкладке «Профиль» (S4b) [Макет].

## 4. Профиль питомца (S4, S4b)

### Поля [Макет]
Все поля обязательные. Варианты выбираются чипами, одним нажатием. Тексты вариантов хранить как есть (с маленькой буквы).

| Поле | Ключ [Предложение] | Тип | Значения / правила | Текст ошибки |
|---|---|---|---|---|
| Кличка | `name` | строка | 1–30 символов, пробелы по краям обрезать | «Укажите кличку» |
| Возраст | `age` | один из | до 6 месяцев · 6–12 месяцев · 1–3 года · 3–7 лет · старше 7 лет · не знаю точно | «Выберите возраст» |
| Пол | `sex` | один из | мальчик · девочка | «Выберите пол» |
| Когда собака появилась дома | `home_since` | дата | ДД.ММ.ГГГГ, выбирается календарём; не позже сегодняшнего дня | «Укажите дату» / «Дата в будущем» |
| Откуда собака | `origin` | один из | из приюта · с передержки · с улицы · от прежних хозяев · от заводчика · другое (без поля уточнения) | «Выберите, откуда собака» |
| Это ваша первая собака? | `first_dog` | один из | да · нет, раньше были собаки · нет, сейчас в доме есть и другие собаки | «Выберите вариант» |

Для API лучше хранить коды, а не тексты, например `age: "under_6m" | "6_12m" | "1_3y" | "3_7y" | "over_7y" | "unknown"` [Предложение].

### Поведение [Макет]
- Ошибки показываются после нажатия «Готово» — у всех незаполненных полей сразу; текст справа в строке с названием поля, название и текст синие; форма прокручивается к первому полю с ошибкой. Ошибка поля исчезает, как только поле заполнено.
- «Назад» и пункты меню **не теряют** введённое: черновик сохраняется, главная переходит в A2, форма потом открывается с этими данными. Окна «Выйти без сохранения?» нет.
- «Готово» → сохранение (кнопка с загрузкой, поля заблокированы) → главная в состоянии B.
- Ошибка сохранения (E8 из ТЗ) в макетах убрана; что показывать при сбое сохранения — [Открыто], можно глобальную E6.
- Черновик хранить на сервере или в браузере — [Открыто]; на сервере удобнее, если пользователь продолжит с другого устройства [Предложение].

### S4b — просмотр [Макет]
- Заголовок «Профиль питомца», значения: Кличка, Возраст, Пол, Дома с, Откуда, Первая собака.
- Раздел «Аккаунт»: «Написать команде», «Выйти».
- **Редактирования профиля в пилоте нет** (кнопки «Изменить» нет). Пункта «Удалить мои данные» нет (в ТЗ был [Открыто]).

Ассистент в чате видит профиль собаки [ТЗ, принято].

## 5. Анкета и план (S5, S7, S9)

Анкета — опросник C-BARQ(S) в переводе Ю. Э. Гербека, как в Яндекс Форме. Все тексты вопросов, описаний разделов и шкал — в `prototype/src/cbarq-questions.json` (опечатки формы исправлены, название раздела 5 изменено на «Поведение, когда собака остаётся одна»).

- **S5** [Макет]: «Анкета адаптации», чип «около 15 минут», иллюстрация, текст «Вопросы анкеты позволят вам описать поведение вашей собаки…» с вариантом «Не наблюдалось или неприменимо», кнопка «Заполнить анкету» → `survey=started` → «Введение».
- **8 разделов** [Макет]: 1 «Введение» (форма), затем C-BARQ: 2 Возбудимость (2 вопроса), 3 Агрессия (10), 4 Страх и тревожность (9), 5 Поведение, когда собака остаётся одна (3), 6 Привязанность и поиск внимания (2), 7 Дрессируемость (3), 8 Разное (13). Всего 42 вопроса, сквозная нумерация «Вопрос N из 42», полоса прогресса.
- **Введение** [Макет]: одна прокручиваемая форма. Поля: сколько людей проживает в доме (число, обязательно, «Укажите число»); есть ли дети (да/нет); кастрация/стерилизация (да/нет); сколько собака содержалась в приюте (7 вариантов) — **только если в профиле «Откуда собака» = «из приюта»** (передержка не считается); метис или породистая (обязательно, «Выберите вариант»); примерный вес, кг (цифры, одна десятичная); примерный рост в холке, см (целое); условия жизни до вас (текст); обращались ли к кинологу/зоопсихологу (3 варианта). Ошибки — справа в строке названия, как в профиле. Кличка, пол, порода, приют, возраст, дата переезда, амуниция, контакт — убраны (кличка и пол уже есть в профиле).
- **Вступление раздела** [Макет]: «Раздел N из 8 · K вопросов», название и описание раздела из C-BARQ без сокращений; длинный текст прокручивается.
- **Вопрос** [Макет]: один вопрос на экран, варианты 0–4 с подписями шкалы раздела и отдельный «X — Не наблюдалось или неприменимо». Разделы 2–4 — шкала силы реакции (у каждого свои подписи), 5–8 — шкала частоты «Нет, никогда … Всегда». Выбранный вариант сиреневый, без тени. Пока ответ не выбран, «Далее» неактивна; в «Дрессируемости» ответ необязателен (как в форме), «Далее» активна сразу.
- **Свободный ответ** [Макет]: в конце каждого раздела 2–8, «Другое о …», необязательный.
- **Перебивка** [Макет]: после каждого раздела, стиль главного экрана S1: синий фон, иллюстрация, «Раздел N из 8 пройден», «Дальше: <раздел> · K вопросов», кнопка «Далее». Текстов поддержки для разделов 1–7 пока нет [Открыто]. После раздела 8: «Отлично, анкета пройдена, теперь можем сформировать профиль питомца и перейти к выполнению плана адаптации.», кнопка «Сформировать профиль» → `survey=done`.
- **Навигация** [Макет]: «Назад» — на предыдущий экран; со вступления раздела — на последний вопрос предыдущего раздела (свободный ответ), перебивку пропускаем; со вступления раздела 2 — на «Введение»; с «Введения» — на S5. На перебивке «Назад» нет. «×» на любом экране анкеты сохраняет ответы и ведёт на главную C без подтверждения.
- Каждый ответ сохранять сразу, позицию в анкете хранить на сервере: продолжить с того же места, в том числе на другом устройстве [ТЗ].
- Куда ведёт «Сформировать профиль» — [Открыто]; в прототипе пока на S9. Экрана профиля питомца по итогам анкеты и плана адаптации ещё нет.
- **S9** [Макет]: иллюстрация и «Сервис в разработке», с нижним меню.

## 6. Чат (S10)

### Принцип [ТЗ]
ИИ-помощник на RAG: отвечает только по загруженным книгам о собаках и учитывает профиль собаки (анкету не видит — допущение). Один постоянный диалог: история сохраняется и показывается при повторном входе, старые сообщения подгружаются при прокрутке вверх. «Нового диалога» нет. Лимита на число вопросов нет. Вложений нет. Сколько последних сообщений учитывает ассистент — [Открыто].

### Экран [Макет]
- Чат открывается только при `profile=done`.
- Сверху закреплён дисклеймер, сообщения прокручиваются под ним: «Чат не заменяет ветеринара или кинолога. В экстренной ситуации обратитесь к специалисту.»
- Приветствие — только при первом открытии: «Привет! Я ИИ-помощник по вопросам ухода за питомцем. Помогу разобраться в вашем вопросе. Что вас интересует?» Кнопок с примерами вопросов нет.
- Под полем ввода: «ИИ может ошибаться». Лимита знаков нет (если появится — E16 из ТЗ).
- Источник ответа под сообщением не показывается.

### Типы ответа ассистента [Макет]
Сервер должен возвращать тип ответа — от него зависит вид сообщения и аналитика.

| Тип [Предложение] | Состояние | Что показываем |
|---|---|---|
| `answer` | C4 | Текст ответа и оценка «Полезно» / «Неполезно» |
| `off_topic` | C5 | «Кажется, вопрос не про собаку» — без оценки |
| `no_answer` | C6 | «В моих материалах нет ответа на этот вопрос. Лучше уточнить у ветеринара или кинолога.» — без оценки |
| `urgent` | C7 | «Это требует очной помощи. Обратитесь в ветеринарную клинику.» — сообщение обведено, без дальнейших советов, без оценки. Список срочных тем согласует специалист [Открыто]; проверять срочность до поиска по книгам [ТЗ, рек] |

### Оценка ответа [Макет]
- «Полезно» и «Неполезно» — переключатели под ответом типа `answer`; повторное нажатие снимает выбор.
- «Неполезно» открывает нижний лист «Что не так?» с полем текста (до 500 знаков) и «Отправить» (активна, когда есть текст). Закрыть лист можно и без отзыва — «Неполезно» при этом остаётся выбранным.
- Сохранять: оценку (`up`/`down`/снята) и текст отзыва.

### Ошибки чата [Макет]
| Состояние | Когда | Что показываем |
|---|---|---|
| C3 | ассистент думает | «Печатает…»; отправка заблокирована, пока нет ответа |
| C8 (E14) | сообщение не дошло до сервера | Пузырь с пунктиром, «Не отправлено», «Повторить» и «Удалить» |
| C9 (E24) | ассистент не ответил за отведённое время | «Не удалось получить ответ» и «Повторить»; вопрос сохраняется |

Из ТЗ, на макетах новой палитры не нарисованы: E15 «Не удалось загрузить сообщения» + «Повторить», E29 «Не получилось обработать сообщение. Переформулируйте» (фильтр), E16 (лимит). Время ожидания ответа — [Открыто].

## 9. Модель данных и запросы [Предложение]

Предложение для старта, чтобы фронтенду и бэкенду договориться о форме данных. Названия и структуру можно менять.

### Сущности
```
User          id, login, password_hash, created_at, is_active
Consent       user_id, accepted_at, text_version
DogProfile    user_id, status (none|partial|done), name, age, sex, home_since (date), origin, first_dog, updated_at
Survey        user_id, status (none|started|done), position (vv|pb:N|in:N|q:N|fr:N), started_at, finished_at, version
SurveyAnswer  user_id, survey_version, question_id (1–42), value (0–4|X), answered_at
SurveyIntake  user_id, people (int), kids, neutered, shelter_stay, breed (mixed|purebred), weight_kg, height_cm, history (text), trainer
SurveyFree    user_id, section (2–8), text
ChatMessage   id, user_id, role (user|assistant), text, kind (answer|off_topic|no_answer|urgent|null),
              status (sent|failed|timeout), created_at, assistant_version, books_version
Feedback      message_id, rating (up|down|null), comment (≤500), updated_at
Event         user_id, name, screen, payload (json), created_at, versions (assistant, books, survey, consent)
```

### Запросы
| Метод | Путь | Что делает |
|---|---|---|

## 11. Чем макеты отличаются от ТЗ v2

| Тема | ТЗ v2 | Сейчас в макетах |
|---|---|---|
| Возраст | дата рождения или «примерно» | 6 вариантов чипами |
| Когда появилась дома | дата или «примерно» | точная дата календарём |
| Откуда собака | приют, улица, заводчик, от знакомых, другое + поле | 6 вариантов, без поля уточнения |
| Первая собака | да / нет | 3 варианта |
| Профиль | кнопка «Изменить», «Удалить мои данные» | только просмотр, «Написать команде» и «Выйти» |
| Выход из формы | окно «Выйти без сохранения?» | черновик сохраняется, состояние главной A2 |
| Анкета | S5 → S6 → S7 → S8 | S5 → анкета C-BARQ (8 разделов, перебивки) → S9; опроса уверенности нет |
| Главная B | статус «Заполнен», «дней дома: N», «Анкета 15 минут» | кличка вместо приветствия, без статусов и «?» |
| Специалист | окно S11 | карточка закрыта, «Сервис в разработке» |
| Чат | примеры вопросов, «Изменить профиль», источник, плашка «Заполните профиль» | ничего из этого; чат открыт только после профиля |
| Дисклеймер, приветствие | длинные тексты | короткие тексты (раздел 6) |
| Ошибки | E4, E8, E32 | убраны |

## 12. Открытые вопросы

1. Что делает нажатие на недоступный пункт меню.
2. Хранение черновика профиля: сервер или браузер.
3. Что показывать при сбое сохранения профиля (E8 убрана).
4. Куда ведёт «Сформировать профиль»; профиль питомца по итогам анкеты и план адаптации — что в них и как устроены.
5. Тексты поддержки на перебивках после разделов 1–7.
6. Срок готовности плана и формат плана.
7. Время жизни сессии; число попыток и время блокировки при неверном пароле.
8. Время ожидания ответа ассистента; сколько последних сообщений он учитывает.
9. Список срочных тем.
10. Адрес Telegram для «Написать команде» и ссылка на текст согласия.
11. Десктопная версия в новом стиле не нарисована.
