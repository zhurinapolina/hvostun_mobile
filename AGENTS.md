# Как переносить интерфейс Хвостуна в рабочий код

Этот файл — инструкция для разработчика и для ИИ-ассистента (Claude Code, Cursor, Copilot и т. п.). Цель — перенести мобильный интерфейс **один в один**: та же разметка, те же стили, те же тексты, то же поведение. Сервер и хранение данных делаются заново по `docs/handoff.md`.

## Источники правды (по порядку)

1. **`handoff/screens/*.html`** — эталон каждого экрана и состояния. Как выглядит эталон в браузере на 390 × 844, так должен выглядеть экран в продукте. Карта эталонов — `handoff/README.md`.
2. **`prototype/src/app.js`** — эталон поведения: переходы между экранами, состояния главной и меню, проверки полей, анкета, чат. Это рабочий код на чистом JS, его логику можно переносить напрямую.
3. **`docs/handoff.md`** — данные, статусы, тексты ошибок, модель данных и запросы к серверу.
4. **`design-system/hvostun-design-system.md`** — токены и компоненты (CSS — раздел 12).
5. **`prototype/src/cbarq-questions.json`** — все тексты анкеты.

Если источники расходятся — прав эталон экрана, затем `app.js`, затем остальное.

## Обязательные правила

1. **Копировать, а не перерисовывать.** Разметку, классы и CSS экрана берите из эталона как есть. Меняйте только способ подставить данные (кличка, ответы, сообщения чата). Не «улучшайте» отступы, цвета, шрифты и размеры.
2. **Стили каждого экрана изолировать.** CSS из блока «стили этого экрана» подключать только к своему экрану (CSS Modules, scoped-стили, Shadow DOM или префикс экрана). **Нельзя сливать стили разных экранов в один глобальный файл**: одинаковые селекторы на разных экранах означают разное, и правила перебивают друг друга.
3. **Общий адаптив — один раз.** Блок «общие правила адаптива» (= `prototype/src/app.css`) подключить глобально. Правила `#panel`, `#frame`, `#kbd` и `@media (min-width:760px)…` для пульта — оболочка прототипа, в продукт не переносить. Контейнерные запросы считаются от `#app` (`container: app / size`) — сохраните корневой `#app` или замените на свой корень с тем же `container`.
4. **Тексты не менять.** Ни слова, ни регистра, ни кавычек «», ни тире —. Варианты ответов анкеты — как в эталоне.
5. **Цвета — только из дизайн-системы.** Новых не добавлять.
6. **Иконки и иллюстрации — встроенные SVG из эталонов** (`fill="currentColor"` у иконок). Иллюстрации DiCreate лицензионные, их не перерисовывать и не заменять.
7. **Поля ввода — не меньше 16 px**, иначе iPhone увеличивает страницу при вводе. Числовые поля (люди, вес, рост) принимают только цифры, вес — с одной цифрой после запятой.
8. **Анкета строится из шаблонов и данных.** Вступление раздела, вопрос и свободный ответ — один шаблон каждый (эталоны `s7-section-*-intro`, `s7-question*`, `s7-free-answer*`) плюс тексты из `cbarq-questions.json`. Маршруты и правила «Назад»/«Далее» — функции `prevOf`, `nextOf`, `anketa`, `vvForm` в `app.js`. Ответ сохранять сразу, позицию — для «Продолжить» на главной.
9. **Состояния — как в эталонах.** Неактивная «Далее» (`.b0`), выбранный вариант (сиреневый, без тени), ошибки у полей (справа в строке названия), загрузка (`aria-busy`), закрытые карточки — ровно как в соответствующих эталонах.

## Как проверить, что перенесено без искажений

1. Каждый экран из `handoff/screens` открыть рядом с вашим на 390 × 844 и сравнить (лучше наложением скриншотов: допустимы только различия сглаживания шрифтов).
2. Пройти сценарий: вход → профиль → анкета (Введение, 7 разделов, выход «×» и продолжение) → план → меню → чат. Ожидаемые шаги — `tests/flow.js` и `docs/handoff.md`.
3. Проверить размеры 320 × 568, 360 × 640, 390 × 844, 430 × 932 и горизонтальное 667 × 375, с открытой клавиатурой и с крупным системным шрифтом: нет наложений, обрезанных и перекрытых кнопок (логика проверки — `tests/matrix.js`).

## Готовый промпт для ИИ-ассистента

> Перенеси мобильный интерфейс Хвостуна в этот проект на [ваш стек] строго по `AGENTS.md`. Эталоны экранов — `handoff/screens` (карта — `handoff/README.md`), логика — `prototype/src/app.js`, данные и запросы к серверу — `docs/handoff.md`, тексты анкеты — `prototype/src/cbarq-questions.json`. Разметку, классы, тексты и CSS экранов копируй без изменений, стили каждого экрана изолируй, общий адаптив из `prototype/src/app.css` подключи один раз. Иди по разделам карты эталонов; после каждого экрана открой его рядом с эталоном на 390 × 844 и убедись, что они совпадают.
