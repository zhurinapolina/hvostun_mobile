# Хвостун — мобильная версия

Макеты мобильной версии сервиса поддержки владельцев собак в период адаптации: экраны в новой палитре, кликабельный адаптивный прототип и дизайн-система.

Источник правды — холст «Хвостун — макеты» в Claude, вкладка «Дизайн · новые цвета». Этот репозиторий — копия макетов и прототипа с холста.

**Что внутри пути:** вход → профиль питомца → анкета C-BARQ (раздел «Введение» одной формой и 7 разделов опросника, 42 вопроса, перебивка после каждого раздела) → портрет собаки → план адаптации: рекомендации выдаются по одной, у каждой чек-лист и отметка результата → «Маршрут пройден». Чат с ИИ-помощником доступен после заполнения профиля.

## Что внутри

| Папка | Что лежит |
|---|---|

| `AGENTS.md` | **Как перенести интерфейс в рабочий код без искажений и как подключить сервер**: источники правды, обязательные правила, адаптив, проверка, готовые промпты для ИИ-ассистента фронтенда и бэкенда |
| `docs/handoff.md` | **Передача в разработку**: экраны, состояния, поля и проверки, тексты ошибок, анкета, чат, правила маршрута рекомендаций, модель данных и запросы к серверу, аналитика, отличия от ТЗ, открытые вопросы |
| `api/openapi.yaml` | Описание запросов между интерфейсом и сервером (OpenAPI 3) |
| `api/examples/` | Готовые примеры ответов сервера в тех же состояниях, что экраны прототипа |
| `handoff/` | Эталоны всех экранов и состояний отдельными страницами (`handoff/screens`), в том числе на маленьком телефоне, горизонтально и с клавиатурой, и карта эталонов (`handoff/README.md`) |
| `prototype/index.html` | Кликабельный адаптивный прототип полного пути одним файлом. На телефоне занимает весь экран, на компьютере показывает рамку телефона и пульт с размерами и переходами к экранам |
| `prototype/test.html` | Тот же прототип без пульта — только экран телефона, для тестов с пользователями |
| `prototype/src/` | Исходники прототипа: `app.js` (логика экранов; места, которые заменяет сервер, помечены «СЕРВЕР:»), `app.css` (адаптив), `build_proto.py` (сборка из досок), `doodle.py` (рисованные иконки), `cbarq-questions.json` (тексты анкеты), `recommendations.json` (тексты пяти рекомендаций), `portrait.json` (пример портрета) |
| `mockups/` | Экраны 390 px, по одной доске на раздел: вход, главная (`V-M-S3-AC`, `V-M-S3-EF`), профиль и ошибки, профиль с портретом (`V-M-S4b-portret`), вход в анкету, анкета (`V-M-S7-vvedenie`, `V-M-S7`, `V-M-S7-perebivki`, `V-M-S7-r2` … `r8`), портрет (`V-M-S8`), план (`V-M-S9-plan`), рекомендация (`V-M-S12-1`, `V-M-S12-2`, `V-M-S12-3-5`), результат и финал (`V-M-S13-S14`), чат, глобальная ошибка. `V-M-S3` и `V-M-S4-dop` — прежние главная и профиль, архив |
| `mockups/variants/` | Доски сравнения, по которым принимали решения: цвет перебивок, выбранное состояние с тенью и без, варианты иконок |
| `design-system/` | Дизайн-система 2 (новые цвета): доска `N-DS.dc.html`, дополнение для портрета и маршрута `N-DS-plan.dc.html`, описание текстом `hvostun-design-system.md` (токены, компоненты, правила, CSS, иконки), стили новых компонентов `plan-components.css` |
| `illustrations/` | Лицензионные иллюстрации DiCreate Dog illustrations, перекрашенные в цвета ДС (`*-blue.svg`, `*-cream.svg`), паттерн фона чата, иллюстрации рекомендаций и аватар (`plan/`) |
| `source/canvas/` | Доски в формате холста (`*.dc.html`) и `canvas.json` — чтобы пересобрать прототип или вернуть доски на холст |
| `tests/` | Проверки прототипа в браузере: сценарий полного пути и матрица размеров |
| `tools/` | Запуск проверок (`run_tests.mjs`) и выгрузка эталонов экранов из прототипа (`export_screens.mjs`) в Chrome без окна |

## Как открыть

Все страницы самодостаточные, картинки и шрифты встроены или берутся из Google Fonts. Можно открыть `index.html` двойным щелчком или запустить локальный сервер:

```bash
python3 -m http.server 8765
```

и открыть http://127.0.0.1:8765/.

## Как пересобрать прототип

```bash
python3 prototype/src/build_proto.py
```

`build_proto.py` берёт разметку и стили каждой доски из `source/canvas`, тексты из JSON-файлов рядом, а `app.css` и `app.js` добавляют адаптив и логику. Получаются `prototype/index.html` и `prototype/test.html`. Стили досок не сливаются в один файл: каждый экран подключает правила своей доски.

После пересборки прототипа обновить эталоны: `node tools/export_screens.mjs`.

## Тесты

```bash
node tools/run_tests.mjs
```

Нужны Node 22+ и Google Chrome, устанавливать ничего не надо. Если Chrome стоит не в обычном месте, путь задаётся переменной окружения `CHROME`. Скрипт открывает прототип в Chrome без окна и запускает:

- сценарий полного пути (`tests/flow.js`, 50 проверок): вход, профиль, вся анкета с выходом и продолжением, портрет, пять рекомендаций с разными результатами, лимит «Не подошла», возврат отложенной, финал, меню, чат;
- матрицу размеров (`tests/matrix.js`): 12 размеров телефона в портрете и горизонтально × обычный шрифт, открытая клавиатура, шрифт × 1,3 — наложения, текст за краем, обрезанные и перекрытые кнопки, мелкие цели нажатия.

Те же проверки можно вызвать руками в консоли браузера на странице прототипа, подключив скрипты из `tests/`: `__flow()` и `__matrix({sizes:[[360,640],[390,844]], kb:true, font:1.3})`.
