# Хвостун — мобильная версия

Макеты мобильной версии сервиса поддержки владельцев собак в период адаптации: экраны в новой палитре, кликабельный адаптивный прототип и дизайн-система.

Источник правды — холст «Хвостун — макеты» в Claude, вкладка «Дизайн · новые цвета». Этот репозиторий — выгрузка с холста на 8 ноября 2026 года (холст v288, прототип v12).

## Что внутри

| Папка | Что лежит |
|---|---|
| `index.html` | Стартовая страница со ссылками на всё ниже |
| `prototype/index.html` | Кликабельный адаптивный прототип одним файлом. На телефоне занимает весь экран, на компьютере показывает рамку телефона и пульт с размерами и переходами к экранам |
| `prototype/src/` | Исходники прототипа: `app.js` (логика экранов), `app.css` (адаптив), `build_proto.py` (сборка из досок), `doodle.py` (рисованные иконки) |
| `mockups/` | Экраны 390 px, по одной доске на раздел: вход, главная A–D, профиль и ошибки, анкета, чат, глобальная ошибка |
| `mockups/variants/` | Доски сравнения, по которым принимали решения: форма кнопок, закрытые карточки, поля |
| `design-system/N-DS.dc.html` | Дизайн-система 2 (новые цвета) |
| `design-system/hvostun-design-system.md` | Та же дизайн-система текстом: токены, компоненты, правила, CSS, иконки — для разработки и генерации |
| `illustrations/` | Лицензионные иллюстрации DiCreate Dog illustrations, перекрашенные в цвета ДС (`*-blue.svg`, `*-cream.svg`), и паттерн фона чата |
| `source/canvas/` | Доски в формате холста (`*.dc.html`) и `canvas.json` — чтобы пересобрать прототип или вернуть доски на холст |
| `tests/` | Проверки прототипа в браузере: экраны, сценарий, клавиатура, матрица размеров |

## Как открыть

Все страницы самодостаточные, картинки и шрифты встроены или берутся из Google Fonts. Можно открыть `index.html` двойным щелчком или запустить локальный сервер:

```bash
python3 -m http.server 8765
```

и открыть http://127.0.0.1:8765/.

## Как пересобрать прототип

```bash
cd prototype/src
python3 build_proto.py ../../source/canvas . ../index.html
```

`build_proto.py` берёт разметку и стили каждой доски, а `app.css` и `app.js` добавляют адаптив и логику. Стили досок не сливаются в один файл: каждый экран подключает правила своей доски.

## Тесты

Подключите скрипты из `tests/` к странице прототипа и вызовите в консоли браузера:

- `__audit()` — все экраны: вылеты за край, перекрытия, размеры касания;
- `__flow()` — сквозной сценарий от входа до чата;
- `__matrix({sizes:[[360,640],[390,844]], kb:true, font:1.3})` — размеры экрана × клавиатура × крупный шрифт.
