# Хвостун — мобильная версия

Макеты мобильной версии сервиса поддержки владельцев собак в период адаптации: экраны в новой палитре, кликабельный адаптивный прототип и дизайн-система.

Источник правды — холст «Хвостун — макеты» в Claude, вкладка «Дизайн · новые цвета». Этот репозиторий — копия макетов и прототипа с холста.

**Что нового:** анкета C-BARQ вместо опроса уверенности — раздел «Введение» одной формой и 7 разделов опросника (42 вопроса), перебивка после каждого раздела, «Сформировать профиль» в конце; пункт меню «План»; «Следующий шаг» на главной — подсказка, не кнопка; ползунок прокрутки на длинных экранах. Описание анкеты для разработки — `docs/handoff.md`, раздел 5.

## Что внутри

| Папка | Что лежит |
|---|---|
| `index.html` | Стартовая страница со ссылками на всё ниже |
| `AGENTS.md` | **Как перенести интерфейс в рабочий код без искажений**: источники правды, обязательные правила, проверка, готовый промпт для ИИ-ассистента |
| `handoff/` | Эталоны всех экранов и состояний отдельными страницами (`handoff/screens`) и карта эталонов (`handoff/README.md`) |
| `docs/handoff.md` | **Передача в разработку**: экраны, состояния, поля и проверки, тексты ошибок, чат, модель данных и запросы к серверу, аналитика, отличия от ТЗ, открытые вопросы |
| `prototype/index.html` | Кликабельный адаптивный прототип одним файлом. На телефоне занимает весь экран, на компьютере показывает рамку телефона и пульт с размерами и переходами к экранам |
| `prototype/src/` | Исходники прототипа: `app.js` (логика экранов), `app.css` (адаптив), `build_proto.py` (сборка из досок), `doodle.py` (рисованные иконки), `cbarq-questions.json` (тексты анкеты: разделы, описания, шкалы, 42 вопроса) |
| `mockups/` | Экраны 390 px, по одной доске на раздел: вход, главная A–D, профиль и ошибки, вход в анкету, анкета (`V-M-S7-vvedenie` — Введение, `V-M-S7` — шаблоны состояний, `V-M-S7-perebivki` — 8 перебивок, `V-M-S7-r2` … `r8` — все вопросы по разделам), чат, глобальная ошибка |
| `mockups/variants/` | Доски сравнения, по которым принимали решения: цвет перебивок, выбранное состояние с тенью и без |
| `design-system/N-DS.dc.html` | Дизайн-система 2 (новые цвета) |
| `design-system/hvostun-design-system.md` | Та же дизайн-система текстом: токены, компоненты, правила, CSS, иконки — для разработки и генерации |
| `illustrations/` | Лицензионные иллюстрации DiCreate Dog illustrations, перекрашенные в цвета ДС (`*-blue.svg`, `*-cream.svg`), и паттерн фона чата |
| `source/canvas/` | Доски в формате холста (`*.dc.html`) и `canvas.json` — чтобы пересобрать прототип или вернуть доски на холст |
| `tests/` | Проверки прототипа в браузере: экраны, сценарий, клавиатура, матрица размеров |
| `tools/` | Выгрузка эталонов экранов из прототипа: `export_screens.js` и локальный приёмник `receiver.py` |

## Как открыть

Все страницы самодостаточные, картинки и шрифты встроены или берутся из Google Fonts. Можно открыть `index.html` двойным щелчком или запустить локальный сервер:

```bash
python3 -m http.server 8765
```

и открыть http://127.0.0.1:8765/.

## Как пересобрать прототип

```bash
cd prototype/src
python3 build_proto.py ../../source/canvas . ../index.html
```

`build_proto.py` берёт разметку и стили каждой доски, а `app.css` и `app.js` добавляют адаптив и логику. Стили досок не сливаются в один файл: каждый экран подключает правила своей доски.

## Тесты

Подключите скрипты из `tests/` к странице прототипа и вызовите в консоли браузера:

- `__audit()` — все экраны: вылеты за край, перекрытия, размеры касания;
- `__flow()` — сквозной сценарий: вход, профиль, вся анкета (42 вопроса, выход и продолжение), план, меню, чат;
- `__matrix({sizes:[[360,640],[390,844]], kb:true, font:1.3})` — размеры экрана × клавиатура × крупный шрифт.
